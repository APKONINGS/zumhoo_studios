# Zumhoo Studios

Cinematic homepage for Zumhoo Studios — a Cameroonian film, television and
photography production studio. Vite + React + Tailwind CSS + GSAP.

Project titles, credits, awards, bios and stats throughout the site are
clearly bracketed placeholders (`[PROJECT TITLE]`, `[AWARD]`, `[FOUNDER BIO]`,
etc.) pending real content — see `src/data/site.js` and `src/data/projects.js`.

## Development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build to dist/
```
